# 潮汐 · 情绪日记与自我关怀

> 情绪会涨，也会退。你不必在浪里硬撑。

一个纯前端、零依赖的情绪日记工具。30 秒记下一次情绪波动，自动归因出是什么在反复触发它，并按情绪类型匹配合适的自助调节方案。

**在线体验**：https://tide-mood-diary-59839.app.workbuddy.host/
（打开后点「看完整演示」，可载入 30 天示例数据直接看完整效果）

---

## 它解决什么

不是「没地方记日记」，而是三个更具体的问题：**说不清、记不下、不知道做什么**。

| 问题 | 做法 |
| --- | --- |
| **说不清** | 情绪六宫格 → 细分情绪 → 强度滑杆，把模糊的感受拆成可以点选的具体词 |
| **记不下** | 全程点选，打字是可选项。情绪最差的时候恰恰最没力气组织语言——传统日记要求「先写出来」，等于把最需要帮助的人挡在门外 |
| **不知道做什么** | 按「情绪 + 唤醒度」匹配 24 个调节方案，而不是随机推一段冥想音频 |

## 四个设计决策

### 1. 把记录门槛压到 30 秒

五步点选：情绪 → 细分 → 强度 → 触发标签 → 身体信号，备注可完全跳过。

### 2. 让记录产生反馈，而不是沉进抽屉

只记录不分析，等于给自己加了一份作业。每条记录拆成「情绪 + 强度 + 触发因素 + 身体信号 + 时段」五个维度，再自动归因成对话式洞察：

> 你的低谷集中在 22:00 之后。深夜的自我评价通常比白天苛刻得多——那是疲惫在说话。

### 3. 推荐按「情绪 + 唤醒度」匹配，而不是按心情随机

焦虑和低落需要的是**相反**的动作：

- 高唤醒的负面情绪（焦虑、愤怒、恐慌）→ 先降生理唤醒：4-7-8 呼吸、冷刺激、发泄
- 低唤醒的负面情绪（低落、无力、自我厌恶）→ 先激活行为与联结：散步、晒太阳、给人发消息

方向搞反，人会更糟。这是推荐逻辑的核心判断。

### 4. 建立闭环：让系统学会「什么对你有效」

每次做完调节后记一次强度变化，累积起来就能算出——在你身上，哪种方法平均回升最多。

这是通用建议和个性化建议的分界线，也是「自我关怀」从一句口号变成一项能力的地方。

## 功能

| 页面 | 内容 |
| --- | --- |
| **记录** | 30 秒点选式打卡；情绪分三态（正面 / 中性 / 负面），自动切换标签库 |
| **日记** | 按日期分组的时间线，可展开详情（身体反应、备注、干预记录）、单条删除、按极性筛选 |
| **洞察** | 对话式归因、情绪日历热力图、触发因素排行、一天中的情绪节律、14 天曲线、干预有效性排行 |
| **关怀** | 24 个方案（呼吸 / 冥想 / 运动 / 音乐 / 书写 / 感官 / 连接 / 保持），内置呼吸引导动画与情绪急救 |
| **我的** | 数据导出（JSON）、统计概览、完整的设计逻辑页 |

**字体、图标、图表全部手写或内联**，没有任何外部 CDN 请求。

## 技术说明

纯静态站点，**零依赖、零构建**——没有框架、没有打包器、没有后端。

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面骨架（43 行） |
| `styles.css` | 设计系统：浅色、低刺激、大圆角 |
| `data.js` | 情绪库 26 种 / 压力源标签 25 + 滋养源标签 24 / 24 个调节方案 |
| `core.js` | 统计归因引擎、洞察文案生成、方案匹配、示例数据生成 |
| `app.js` | 视图渲染、交互分发、弹层、呼吸动画 |

### 数据与隐私

所有记录只保存在这台设备的浏览器本地（`localStorage`），**不上传服务器、不需要注册登录**。

情绪是最敏感的数据之一——一个情绪日记产品如果先问你要手机号，就已经输了一半。

### 两个刻意的取舍

- **不做社交**：情绪记录一旦有观众，人就会开始表演。所以没有点赞、没有排行榜、没有分享按钮。
- **不做 AI 对话入口**：对话框要求用户主动组织语言，门槛反而更高。AI 更适合放在洞察层，而不是入口层。

## 本地运行

```bash
# 方式一：起个本地静态服务（推荐，更接近真实环境）
python -m http.server 8000
# 浏览器打开 http://localhost:8000

# 方式二：直接双击 index.html 也可以，但部分浏览器的 localStorage 行为会受限
```
